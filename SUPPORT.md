# Getting Support

## Start with the Wiki

The [Pasted Wiki](https://github.com/getpasted/pasted/wiki) covers installation, everyday workflows, CLI usage, backup and recovery, platform support, privacy, diagnostics, and troubleshooting.

For a problem, check these details first:

- Pasted version from **Settings → About**;
- operating system and version;
- installation source;
- whether the behavior also occurs with the latest release;
- relevant feature, permission, display-server, or provider state;
- diagnostic output with clipboard contents, credentials, and personal paths removed.

## Public issues

Use [GitHub Issues](https://github.com/getpasted/pasted/issues) for reproducible bugs and focused product improvements. Search existing issues first, use the closest issue form, and include a minimal reproduction.

Pasted is maintained as an open-source project. Response times are best effort, and the issue tracker is not an emergency or private support channel.

## Security and privacy

Do not post vulnerabilities, leaked clipboard data, credentials, private file paths, or another person's information publicly. Follow [SECURITY.md](SECURITY.md) and use [GitHub private vulnerability reporting](https://github.com/getpasted/pasted/security/advisories/new).

## Unsupported environments

The latest release documentation defines supported platforms. We still welcome precise reports from experimental environments, but may ask for community help or defer a fix when the failure is in an unsupported operating system, compositor, packaging format, or third-party provider.
